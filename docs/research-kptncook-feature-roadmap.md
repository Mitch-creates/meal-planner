# KptnCook-Inspired Future Roadmap

## Method

This roadmap uses public product-pattern inspiration only. It excludes proprietary scraping and requires licensed or first-party content.

## Top candidate features

### Implement now (MVP-compatible)

1. 3-card daily dinner inspiration
2. Weekly dinner planner as default home
3. Explicit plan confirmation as only quota-consuming action
4. Swap/randomize without quota burn
5. Grocery aggregation with normalized units
6. Step-by-step cooking mode
7. Unlimited favorites
8. "Want to cook" shortlist

### Phase 2

1. Diet/intolerance filters for feed/planner
2. Nutrition facts per serving
3. Trend packs (Pro)
4. Household shared plans and groceries (Pro)
5. Servings scaler

### Post-MVP

1. Personal notes on recipes/plans
2. AI substitution helper with strict allergy guardrails

## Recommended sequence

### Next 3

1. Daily inspiration + weekly planner shell
2. Quota-safe planning loop (confirm-only burn)
3. Grocery aggregation + cooking mode + favorites baseline

### Next 6

1. Want-to-cook shortlist
2. Trend packs (Pro)
3. Household sharing (Pro)
4. Diet/intolerance filters
5. Servings scaler
6. Nutrition facts

### Later

1. Notes
2. AI substitution helper
