# 50 - Definition of Done

A task is done only when all criteria below are satisfied.

## Functional

- Acceptance criteria met and verified.
- No unexpected regressions in adjacent flows.
- UX behavior aligns with MVP contract.

## Technical

- Code reviewed and merged.
- Tests pass in CI/local agreed pipeline.
- Migrations are reversible or safely forward-only with documented rationale.

## Safety and compliance

- Safety Agent signed off release gate.
- No critical/privacy/security issues unresolved.
- Billing and entitlement checks validated.

## Documentation

- Relevant `plan/` and `rules/` docs updated.
- API/data model changes documented.
- Any unresolved tradeoffs captured in backlog or risks.
